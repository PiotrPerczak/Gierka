AnkleBreaker Studio - Render pipeline upgrades

The pack's materials are built for the Built-in render pipeline. Each subfolder here holds the
URP and HDRP versions of one pack's materials, as .unitypackage files.

1. The pack opens on its Welcome window the first time. Its pipeline band tells you whether the
   materials match your render pipeline and offers a one-click conversion. Only the files of the
   matching upgrade package are replaced, at the same paths, so prefabs and scenes keep working.
2. The menu Tools > AnkleBreaker > Apply Render Pipeline Upgrade does the same at any time.
3. You can also import the matching .unitypackage from this folder by hand.

A wrong pipeline shows as pink materials in Built-in and URP, and as black materials in HDRP.

Once your materials match, you can delete this folder.
