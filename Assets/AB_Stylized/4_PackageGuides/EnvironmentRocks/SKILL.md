# Stylized Environment Rocks

Read [AssetLibrary.md](AssetLibrary.md) for the supplied asset paths. Paths are relative to this guide.

1. Select ClickMe-EnvironmentRocks.asset at the AB_Stylized root or open Tools > AnkleBreaker > Stylized Environment Rocks > Welcome.
2. Open the demo scene and inspect the supplied prefabs before placing them in your scene.
3. Choose prefab variants and duplicated materials for customization; preserve supplied files and GUIDs.
4. Check the pipeline status in CLICKME before using the materials in URP or HDRP.

These are visual assets. No gameplay system is provided by this guide. The collection contains 368 prefab assets and 1 demo scene(s).
